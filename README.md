# My LC Notes

My notebook for LeetCode practices — one problem a day.

## How to Use

1. Copy `TEMPLATE.md` → `solutions/NNNN_ProblemTitle.md`
2. Fill in the template
3. Run the Java `main` method directly in VS Code (requires [Extension Pack for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack))
4. Commit daily to keep the streak

```
My LC Notes/

    └── ...
```
