# 0001. Two Sum - C

**Difficulty:** Easy
**Tags:** `Array` `Hash Table`
**Date:** 2026-05-22
**Link:** [LeetCode](https://leetcode.com/problems/two-sum/)

## Problem Summary

> Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

**Example:**
```
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Input: nums = [3,2,4], target = 6
Output: [1,2]

Input: nums = [3,3], target = 6
Output: [0,1]
```

**Constraints:**
- 2 <= nums.length <= 104
- -109 <= nums[i] <= 109
- -109 <= target <= 109

---

## Approach

**Strategy:** *Nested Forloop/HashMap in C*

Key observations:
- C need to set the result size accordingly and free/clean up at the end
- C does not have standard HashMap, so if want to implement in HashMap need to write a HashMap by ourselves.

---

## Complexity

|  | **Time** | **Space** |
|---|---|---|
| **Brute Force** | O(n^2) | O(1) |
| **HashMap** | O(n) | O(n) |

## Solution (Brute Force)

```C
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++){
            for (int j = i + 1; j < nums.length; j++){
                if (nums[j] == target - nums[i]){
                    return new int[] {i, j};
                }
            }
        }
        return new int[]{};
    }
}
```

```C
#include <stdlib.h>

#define TABLE_SIZE 20011  // a prime, comfortably larger than max numsSize (10^4)

typedef struct Node {
    int key;            // the number
    int idx;            // its index in nums
    struct Node* next;
} Node;

static int hash(int key) {
    // handle negatives; modulo with prime table size
    return ((key % TABLE_SIZE) + TABLE_SIZE) % TABLE_SIZE;
}

int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    Node** table = calloc(TABLE_SIZE, sizeof(Node*));  // zero-initialized
    int* res = malloc(sizeof(int) * 2);
    *returnSize = 0;

    for (int i = 0; i < numsSize; i++) {
        int complement = target - nums[i];
        int h = hash(complement);

        // Look up complement in its bucket
        for (Node* cur = table[h]; cur != NULL; cur = cur->next) {
            if (cur->key == complement) {
                res[0] = cur->idx;
                res[1] = i;
                *returnSize = 2;
                goto cleanup;  // free table before returning
            }
        }

        // Not found — insert nums[i] into its bucket
        int h2 = hash(nums[i]);
        Node* node = malloc(sizeof(Node));
        node->key = nums[i];
        node->idx = i;
        node->next = table[h2];
        table[h2] = node;
    }

cleanup:
    // Free all nodes in every bucket
    for (int i = 0; i < TABLE_SIZE; i++) {
        Node* cur = table[i];
        while (cur != NULL) {
            Node* tmp = cur;
            cur = cur->next;
            free(tmp);
        }
    }
    free(table);
    return res;
}
```
